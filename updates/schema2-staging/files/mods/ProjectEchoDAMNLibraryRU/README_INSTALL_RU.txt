PROJECT ECHO - THAT DAMN LIBRARY RU | v1.0.0 | PZ B42.21

Источник перевода: Workshop 3171167894, that DAMN Library (damnlib), ветка B42.20/common.
Обработаны 2004 ключа из английских таблиц, включая названия частей автомобилей KI5,
инвентарь, рецепты, параметры песочницы, подсказки и названия жидкостей.
Названия брендов и моделей автомобилей намеренно сохранены как торговые обозначения.
Служебные HEADER_ ключи/Workshop ID также оставлены без изменений.

УСТАНОВКА:
1. Положите папку ProjectEchoDAMNLibraryRU в %USERPROFILE%\Zomboid\mods\
2. Оставьте оригинальный damnlib активным.
3. В Mods=servertest.ini добавьте ;ProjectEchoDAMNLibraryRU ПОСЛЕ оригинального damnlib.
4. В WorkshopItems ничего добавлять не нужно (локальный мод без Workshop ID).
5. Скопируйте ту же папку клиентам через PROJECT ECHO Launcher; перезапустите игру.

Мод содержит только файлы RU локализации, без кода и игровых ресурсов DAMN Library.
Язык интерфейса Project Zomboid должен быть Русский.
Проверено: JSON, соответствие английским ключам, подстановки %1.
Совместимость в живой сессии B42.21 пока не проверялась.

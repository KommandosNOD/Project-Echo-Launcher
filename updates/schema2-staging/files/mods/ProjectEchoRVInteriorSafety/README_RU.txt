PROJECT ECHO / RV INTERIOR SAFETY v0.2.0 TEST / B42.21 MP

ЭТО ОБНОВЛЕНИЕ СТАРОГО МОДА, не дополнительный мод.
Mod ID: ProjectEchoRVInteriorSafety (НЕ МЕНЯЛСЯ).

Что исправлено:
- Сохранена существующая защита входа в RV: временная защита от падения, проверка пола, возврат при неудачном входе, восстановление прежнего GodMode.
- Добавлена проверка данных персонажа ПЕРЕД вызовом оригинального RVServer.GetOutFromRV.
- Если запись потеряна, на сервере однозначно сопоставляется AssignedRooms и серверная позиция автомобиля. Если совпадений 0 или более 1, возврат отклоняется без телепортации.
- Предотвращена отправка оригинальной команды выхода при отсутствии сохраненной позиции автомобиля. Оригинал может очистить ActualRoom до проверки наличия Vehicles[id].
- Добавлен запасной выход CTRL+SHIFT+F9, а также второй пункт в меню ПКМ (для Viewpoint 3D и изометрии).
- Для обычного выхода используется ОРИГИНАЛЬНЫЙ серверный механизм PROJECTRVInterior42. Клиент сам координаты выхода не задаёт.
- При штатном выходе завершается ожидающая серверная защита входа, чтобы не случился ошибочный аварийный возврат по таймауту.
- Подробные сообщения [PE-RV-Safety] при отказе или успешном вызове оригинального выхода.

УСТАНОВКА
1. ОСТАНОВИ сервер и закрой игру, сделай резервную копию мира и персонажей.
2. Удали старую папку ProjectEchoRVInteriorSafety на КЛИЕНТЕ и СЕРВЕРЕ, не трогая PROJECTRVInterior42.
3. Положи НОВУЮ папку ProjectEchoRVInteriorSafety в Zomboid/mods на КЛИЕНТЕ и СЕРВЕРЕ.
4. В Mods= оставь ОДИН ;ProjectEchoRVInteriorSafety. WorkshopItems= не менять.
5. Если успел поставить экспериментальный ProjectEchoRVExitFix, УБЕРИ его ИЗ Mods= и удали его папку; одновременно два выходных фикса не включать!
6. Перезапусти сервер и клиент.

ПРОВЕРКА
- Войдите в тестовый RV в изометрии, потом в Viewpoint.
- Для выхода ПКМ по полу -> штатное «Выйти из RV», либо CTRL+SHIFT+F9.
- На сервере должен появиться: [PE-RV-Safety][server] v0.2.0 hooked original RVServer.GetOutFromRV
- При запросе выхода: [PE-RV-Safety][server] EXIT <имя> status=native-exit-invoked reason=...
- На клиенте: [PE-RV-Safety][client] native RV exit packet received, затем EXIT SUCCESS
- При отказе: EXIT ... status=declined reason=..., передайте этот лог для дальнейшего разбора.

ЗАЩИТА И ОГРАНИЧЕНИЯ
- Патч НЕ проверен в живом PROJECT ECHO — сначала тестировать на КОПИИ мира.
- Не трогать карты и чанки; нет безусловного телепорта и синхронизации мировой позиции по произвольным данным клиента.
- Сохраняет логику временного GodMode оригинального Safety v0.1.0; проверяй его восстановление после входа.
- Из-за сложных модов RV/Views могут остаться другие причины невозможности выхода.
- Не удаляет исходные скрипты PROJECTRVInterior42, карту и сохранение мира.

ОТКАТ
Заменить папку на исходную ProjectEchoRVInteriorSafety v0.1.0 и перезапустить.

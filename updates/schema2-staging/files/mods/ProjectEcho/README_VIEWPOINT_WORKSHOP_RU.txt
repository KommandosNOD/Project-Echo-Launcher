PROJECT ECHO 2.0.4 - ViewpointUI translations as a lightweight patch.
Workshop ID: 3812616893 / Mod ID: ViewpointUI.
The ViewpointUI Lua modules and ViewpointUI.jar are NOT included in ProjectEcho.
The addon changes ViewpointUI.Text entries in RAM after Workshop loads, without replacing original source files.
Russian translations: 42/media/lua/shared/Translate/RU/UI.json.
NOTE: ModOptions labels, private text-truncation functions, and any UI strings hardcoded directly in the upstream module are not overridden by this safe patch.

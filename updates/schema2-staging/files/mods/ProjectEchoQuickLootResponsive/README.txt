READY TO COPY! This ZIP contains the mod folder itself, no installer.

Installation:
1. Close Project Zomboid.
2. Copy ProjectEchoQuickLootResponsive folder to:
   C:\Users\KommandosNOD\Zomboid\mods\
   (other players: %USERPROFILE%\Zomboid\mods\)
3. On the server, append ;ProjectEchoQuickLootResponsive to the Mods= line.
   Do not modify WorkshopItems= or Map=.
4. Copy the SAME folder to the client or include it in PROJECT ECHO Builder.
5. Ensure ViewpointUI is installed; place this mod AFTER ViewpointUI in the mod order.
6. Start game and look for [PE-QuickLootResponsive] active in console.txt.

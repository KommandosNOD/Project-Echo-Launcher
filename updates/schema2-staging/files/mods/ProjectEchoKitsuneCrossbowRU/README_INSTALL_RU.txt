Установка:
1) ПОЛНОСТЬЮ закрыть Project Zomboid у себя и у друзей.
2) Распаковать архив в %USERPROFILE%\Zomboid\mods\
   Согласиться на замену папки ProjectEchoKitsuneCrossbowRU.
3) Mod ID сохраняется: ProjectEchoKitsuneCrossbowRU
   В servertest.ini сохраните порядок:
   ...;alicesKitsunesCrossbowMod;ProjectEchoKitsuneCrossbowRU
4) Установить такую же папку на КАЖДЫЙ клиент через PROJECT ECHO Launcher
   (для локальной русификации WorkshopItems не требуется).
5) Перезапустить клиент и переподключиться к серверу.
6) Убедиться, что язык игры Русский и мод перевода активирован на КЛИЕНТЕ.

Оригинал Workshop 3783567014 не меняется. Мод содержит только файлы локализации.

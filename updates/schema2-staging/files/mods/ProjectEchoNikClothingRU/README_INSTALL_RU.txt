PROJECT ECHO — NIK RANDOM CLOTHING RU v1.0.0
Для Project Zomboid Build 42.21 MP

Переведены 100 названий предметов (99 из английского ItemName.json и
1 пропущенный автором), 17 строк контекстного меню, 5 рецептов.

ПРИМЕР:
Half Hoodie -> Укороченное худи

УСТАНОВКА:
1. Закройте игру.
2. Распакуйте ProjectEchoNikClothingRU в папку
   C:\Users\KommandosNOD\Zomboid\mods\
   Должно получиться: ...\mods\ProjectEchoNikClothingRU\42\media\...
3. Оригинальный Random Clothing (Workshop ID 3397182976,
   Mod ID RandomClothing) должен остаться включенным.
4. Добавьте ;ProjectEchoNikClothingRU В КОНЕЦ Mods= в servertest.ini,
   ПОСЛЕ RandomClothing. Не добавляйте Workshop ID для перевода.
5. Для клиента (Launcher): установите ту же папку локального мода
   каждому игроку, активируйте его в списке клиентских модов.
   Серверная установка сама по себе не гарантирует клиентскую локализацию.
6. Полностью перезапустите клиент; язык интерфейса — Русский.

Все JSON-файлы проверены; работа внутри реальной игровой сборки
не проверялась. Исходные Workshop-файлы и 3D-модели не изменялись.

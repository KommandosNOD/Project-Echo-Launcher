PROJECT ECHO - Hand Models Fix v0.2 (B42.21) / ТЕСТ

Добавлено исправление визуального размера ванильных спальных мешков,
в том числе сложенных и разложенных, когда они в руках персонажа.
Исправление сломанной короткой рукояти из v0.1 сохранено.

УСТАНОВКА:
1. Распакуйте архив полностью.
2. Закройте игру.
3. Запустите INSTALL.bat. При необходимости укажите путь к игре.
4. Не включайте второй мод: ID остался PEBrokenSmallHandle3DFix.
5. Перезапустите игру и проверьте рукоять, спальный мешок в руках,
   его раскладывание, сворачивание и размещение на земле.

Установщик читает исходные скрипты моделей из каталога установленной игры,
создаёт их уменьшенные копии (35% исходного масштаба) в папке мода.
Оригинальные игровые файлы НЕ изменяются.

Путь установки:
C:\Users\<имя>\Zomboid\mods\ProjectEcho_BrokenSmallHandle_Fix

Логи: Zomboid\console.txt — ищите строки [PE-3DFix].
Если в INSTALL.bat отображается предупреждение об отсутствии моделей,
нужно указать точную папку игры, содержащую media\scripts.

ВЕРСИЯ ТЕСТОВАЯ: с Viewpoint пока не проверено на вашем клиенте.
Для сервера сначала протестируйте отдельно, затем раздавайте клиентам
всю созданную папку мода (включая 42\media\scripts).

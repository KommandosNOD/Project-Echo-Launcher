PROJECT ECHO — A-LIFE RU v0.1.0 TEST
Исходники: A-LIFE 1.4.6, старый RU EASY 1.7.4, Viewpoint x A-LIFE 1.4.0.

Это редакторская надстройка над существующей русификацией EASY, а не её полная замена.
ОСТАВЬ ВКЛЮЧЁННЫМИ: ProjectALifeNPCs, ProjectALifeNPCsRU_Easy, ViewpointALife (если используешь 3D).
Старый HARD и отдельный Jeem RU (устаревшие) включать не надо.

ЧТО СДЕЛАНО:
- 43 новых строк интерфейса A-LIFE 1.4.6, которых нет в текущем RU.
- 5 новых строк настроек транспорта NPC.
- 30 строк Viewpoint x A-LIFE переведены полностью.
- 81 улучшений формулировок интерфейса, 34 настроек.
- 33 устаревшие числовые значения по умолчанию исправлены в подсказках.
- 85 живых NPC-реплик отредактированы в клиентском словаре RU Easy.
- 2 ключевые подсказки сложности/численности переписаны вручную.
- 16 неверных подписей с %% исправлены по оригиналу.

КАК УСТАНОВИТЬ:
1. Закрыть игру. Для изменения Mods= — остановить сервер.
2. Папку ProjectEchoALifeRU из ZIP распаковать в C:\Users\KommandosNOD\Zomboid\mods\.
3. В servertest.ini добавить ;ProjectEchoALifeRU ПОСЛЕ ProjectALifeNPCsRU_Easy и ViewpointALife.
4. WorkshopItems не менять: локальный мод без Workshop ID.
5. Если используешь Builder PROJECT ECHO — опубликовать этот локальный мод через штатную синхронизацию.
6. Для проверки NPC-реплик в клиентском console.txt искать:
   [ProjectEchoALifeRU] dialogue polish active: 85 phrases

ОТКАТ: убрать ;ProjectEchoALifeRU из Mods=. Игровой мир, SandboxVars, исходники и JAR остаются нетронуты.

ОГРАНИЧЕНИЯ:
Это первый проход. Большие словари исходного RU (много десятков МБ) оставлены активными.
Переработана только часть разговоров NPC. Новый перевод не меняет игровой баланс.
После обновления A-LIFE проверять отсутствующие ключи и сохранность перекрытия переводов.
Не добавлять одновременно с отключением оригинального ProjectALifeNPCsRU_Easy:
клиентский диалоговый словарь использует именно его ProjectALifeRU.Map.

PROJECT ECHO - DEAD DAYS: STORYTELLER / RU OVERLAY 0.1.0

ВАЖНО: ЭТО ПЕРВАЯ ЧАСТИЧНАЯ ЛОКАЛИЗАЦИЯ, НЕ 100% ПЕРЕВОД.
ПОЛНОСТЬЮ ПЕРЕВЕДЕНЫ: настройки Sandbox; основные элементы интерфейса и типовые подсказки.
ЧАСТИЧНО: сюжет первого акта (вводное радио, первые диалоги), типовые задания и реплики напарников.
ОСТАЛИСЬ НА АНГЛИЙСКОМ: значительная часть остальных диалогов, событий и описаний миссий.
Список кандидатов и состояние находится в TRANSLATION_AUDIT.csv.

УСТАНОВКА
1. Закрой Project Zomboid.
2. Скопируй папку ProjectEchoDeadDaysRU в C:\Users\KommandosNOD\Zomboid\mods\
3. Подключи оригинальный DeadDaysStoryteller (Workshop ID 3816904815).
4. В списке Mods после DeadDaysStoryteller добавь ProjectEchoDeadDaysRU.
5. Игроки, которым нужен русский интерфейс, должны установить перевод на клиент.
6. Не изменяй сам Workshop-мод и не заменяй файлы в steamapps/workshop.

КАК РАБОТАЕТ
Текст переводится только при отображении на клиенте (внутри окна сюжета и журнала).
Сюжетные ID, имена функций, логика заданий, файлы сохранения и голосовые хеши не меняются.
Английская озвучка остаётся оригинальной. Для строк на кириллице анимация печати
отключается, чтобы не резать UTF-8 символы по байтам.

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
* В B42.21 MP не тестировалось в игре; Lua-синтаксис и отображение проверены статически.
* Некоторые элементы контекстного меню и системные сообщения могут оставаться на английском.
* Динамические строки, не совпадающие с шаблонами, остаются на английском.
* Перевод не содержит изменения английских звуков/озвучки.
* Новые версии оригинала могут добавлять строки, которых пока нет в словаре.

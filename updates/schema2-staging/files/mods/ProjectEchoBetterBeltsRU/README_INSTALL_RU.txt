13 item names, 15 recipes, crafting category + 3 named equipment slots.
Translated in B42 JSON format: ItemName.json uses Module.Item IDs, Recipes.json
uses the bare craftRecipe name. Includes underscore fallback for multiword recipes.
Slot-name translation changes ONLY name fields of known hotbar entries on
OnGameStart; all attachment maps and equipment behavior are left untouched.

Install: extract ProjectEchoBetterBeltsRU directly into:
  %USERPROFILE%\Zomboid\mods\ProjectEchoBetterBeltsRU
Add after BetterBeltsB42 in your server Mods= line:
  ;ProjectEchoBetterBeltsRU
For multiplayer, distribute to all clients; client must activate the translation.
Restart Project Zomboid and select Russian language to verify.

PROJECT ECHO: ОБМЕН ДЕНЕГ НА PHUNWALLET (B42.21)

Установка:
1. Скопировать папку ProjectEchoMoneyExchange в C:\Users\KommandosNOD\Zomboid\mods
2. Такую же папку установить ВСЕМ игрокам через PROJECT ECHO Launcher.
3. Добавить в конец Mods= в servertest.ini: ;ProjectEchoMoneyExchange
4. WorkshopItems= не изменять. Мод phunmart2 (Workshop 3689006725) оставить активным.
5. Полностью перезапустить сервер и клиентскую игру.

Использование: положить Base.Money в собственный инвентарь или рюкзак;
нажать ПКМ на деньгах (1/10/50/все) или F8 (все).
1 купюра = $0.05, 142 купюры = $7.10.

ОБЯЗАТЕЛЬНО сначала проверить на тестовом персонаже с 1-10 купюрами.
Это исходники для B42.21, проверены статически, но не тестировались
в запущенной игре/выделенном сервере. При ошибке пришли console.txt.

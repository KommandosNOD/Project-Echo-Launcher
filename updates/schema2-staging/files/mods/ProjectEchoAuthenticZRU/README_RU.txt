PROJECT ECHO — AUTHENTIC Z RU (B42.21) v1.0.0
================================================
Workshop оригинала: 2335368829
Исходный вариант: Authentic Z - Current
Mod ID оригинала: Authentic Z - Current
Mod ID перевода: ProjectEchoAuthenticZRU

УСТАНОВКА
1. Из ZIP скопируйте папку ProjectEchoAuthenticZRU в
   C:\Users\KommandosNOD\Zomboid\mods\ProjectEchoAuthenticZRU
   (или %USERPROFILE%\Zomboid\mods\ProjectEchoAuthenticZRU).
2. Повторите копирование на сервере и КАЖДОМ клиенте.
3. В servertest.ini в конце существующей строки Mods= допишите
   ;ProjectEchoAuthenticZRU
4. WorkshopItems= НЕ меняйте: перевод является локальным модом.
5. Оставьте исходный Authentic Z - Current включённым.
6. Перезапустите сервер и полностью закройте/запустите игру на клиентах.
7. В настройках языка выберите русский.

ЧТО ВНУТРИ
В папке 42/media/lua/shared/Translate/RU лежат JSON (основной B42)
и парные TXT для тех же ключей. В архивах только текстовые переводы.
Никаких исправлений кода, скриптов предметов, моделей, текстур, звуков.
Оригинальный Authentic Z и остальные его варианты НЕ изменены.

ПРОВЕРКА
Найдите в игре: парики, спортивные бутылки, новые сумки, пункты
управления слотами рюкзаков и всплывающие подсказки.
Если некоторые строки всё ещё по-английски, см. TRANSLATION_AUDIT.csv:
этот файл перечисляет нерешённые строки исходного архива.

Совместимость с другими RU-патчами: порядок Mods= должен быть таким,
чтобы ProjectEchoAuthenticZRU находился ПОСЛЕ исходного Authentic Z.
В случае других русификаторов тех же ключей возможны переопределения.

Проверено: состав ZIP, формат JSON, отсутствие дублей ключей.
Не проверено: запуск на живом сервере B42.21.

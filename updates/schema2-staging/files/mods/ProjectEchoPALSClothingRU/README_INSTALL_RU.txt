УСТАНОВКА (клиент)
1. Распакуйте папку ProjectEchoPALSClothingRU в
   C:\Users\<USERNAME>\Zomboid\mods\
2. Включите мод в списке модов B42.21; локальному моду НЕ НУЖЕН Workshop ID.
3. Перезапустите игру, убедитесь, что язык игры — Русский.
4. В PROJECT ECHO Launcher распространите ЭТУ ЖЕ папку всем клиентам.

Если перевод является частью серверной строки Mods=, добавьте
  ;ProjectEchoPALSClothingRU
после активных Mod ID PALSJ. Не заменяйте текущую строку Mods=!
Не добавляйте перевод в WorkshopItems=; оригинальный Workshop 3683898699 остается прежним.

Проверки: ключи предметов собраны из исходных скриптов; JSON проходит
проверку синтаксиса. Проверка отображения в самой игре остаётся за игроком.

Примеры:
PALShit.CargoPants -> Мамины джинсы с карманами
PALShit.CatEarHelmet -> Мотошлем с кошачьими ушками
PALPalettes.NailPolish -> Флакон лака для ногтей
